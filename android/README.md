# «Погружение» на Android

Android-приложение упаковывает **существующую React/Vite-сборку сайта** в WebView. Ридер, правила погружения, задания, словарь, грамматика, экран профиля и стили берутся из веб-приложения. Отдельной реализации учебных механик на Kotlin больше нет.

## Сборка

Нужны Node.js 20+, JDK 17 или 21 и Android SDK Platform 36. Из корня репозитория:

```powershell
npm ci
cd android
.\gradlew.bat :app:assembleDebug
```

Gradle сам выполняет `npm run build:android-web`, затем кладёт готовый сайт в APK. Результат: `android/app/build/outputs/apk/debug/app-debug.apk`. Установка: `adb install -r android/app/build/outputs/apk/debug/app-debug.apk`.

Телефонные правила размера и переноса элементов живут только в `android/app/android-phone.css`; исходные компоненты сайта и алгоритмы не изменяются. Озвучка использует Android TextToSpeech через небольшой мост в сборке APK. Внешние ссылки открываются системным браузером.

## Данные и сеть

Уроки, словарь и логика сайта находятся в APK и доступны без сети. Прогресс хранится в локальном хранилище WebView этого приложения. Оно **не разделяется** с Chrome, другим браузером или старой Kotlin-версией APK; автоматической синхронизации между ними нет. При обновлении APK с тем же `applicationId` данные WebView сохраняются, если не удалять данные приложения. Внешнее слушание и загружаемые шрифты требуют интернет.

## Проверка

На эмуляторе проверены запуск, onboarding, список уроков и ридер. В уроке «Доброе утро» пресет 95% дал 65 иностранных из 68 ключевых слов (фактическая доля 96% из-за округления) — тот же расчёт, что в браузере. Также проходят `npm run lint`, `npm run test:grammar` и сборка APK.
