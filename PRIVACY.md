# Политика конфиденциальности

**Погружение** — приложение для постепенного изучения языков. Документ описывает, какие данные
приложение обрабатывает и куда они попадают.

Последнее обновление: 28 сентября 2026.

## Какие данные обрабатываются

**Данные аккаунта.** При входе через Google приложение получает адрес электронной почты, имя
профиля и фотографию профиля Google. Запрашиваются только области `openid`,
`auth/userinfo.email` и `auth/userinfo.profile`. Доступ к почте, диску, контактам и другим
сервисам Google не запрашивается.

**Учебный прогресс.** Выученные слова, пройденные уроки, расписание повторений, стрик, история
занятий, ответы на грамматические упражнения и загруженные вами тексты.

**Аватар.** Выбранная вами фотография профиля остаётся на устройстве и **никогда не
отправляется на сервер**. В облако уходит только учебный прогресс.

## Где хранятся данные

Учебный прогресс хранится в базе данных Supabase, в одной строке на пользователя. Доступ к
строке ограничен политиками безопасности на уровне строк: прочитать или изменить её может
только владелец сессии, авторизованный под тем же идентификатором пользователя.

Прогресс также хранится в локальном хранилище устройства. Локальная копия — основная: приложение
полностью работоспособно без аккаунта и без сети.

## Сторонние сервисы

**Google** — аутентификация. Приложение видит только перечисленные выше данные профиля.

**Сервисы синтеза речи** — Edge-TTS, Google Translate TTS и, как резервный вариант, Youdao
доступны через серверный прокси `/api/tts`. При озвучке фрагмент текста передаётся этому
прокси, который обращается к перечисленным поставщикам для генерации аудио. Внутри приложения
на Android используется системный синтезатор речи устройства, и текст наружу не передаётся.

**Внешние ссылки** — раздел «Слушание» ведёт на сайты издателей. Приложение не скачивает и не
зеркалирует их материалы.

## Чего приложение не делает

- Не продаёт и не передаёт данные третьим лицам.
- Не показывает рекламу и не использует трекеры.
- Не запрашивает контакты, местоположение, файлы и микрофон.

## Удаление данных

Удаление аккаунта в Supabase Auth каскадно удаляет строку прогресса. Локальную копию на
устройстве можно стереть кнопкой сброса прогресса в профиле приложения.
